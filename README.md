# Dashboard de Vendas 🛒

Este projeto é um **dashboard interativo de vendas** desenvolvido com **Streamlit** e **Plotly**.  
O objetivo é explorar dados de vendas a partir de um arquivo JSON, exibindo métricas como:

- Receita total e quantidade de vendas  
- Receita por estado (mapa interativo)  
- Receita mensal (linha do tempo)  
- Receita por categoria  
- Ranking de vendedores por receita e por quantidade de vendas  

Também há filtros dinâmicos que permitem refinar os dados por vendedor, categoria, faixa de preço, local e data da compra.
